# Calculadora-IMC
Calculadora de IMC (Índice de Masa Corporal)

¡Bienvenido/a a la Calculadora de IMC! Una aplicación práctica, accesible y fácil de usar diseñada para calcular el Índice de Masa Corporal y proporcionar una clasificación rápida sobre el estado nutricional del usuario.
Características Principales

 Cálculo Preciso: Obtén tu resultado de IMC de forma inmediata ingresando peso y altura.
Categorización Clara: Muestra la clasificación según los rangos estándar de la OMS (Bajo peso, Peso normal, Sobrepeso, Obesidad).

 Interfaz Amigable: Diseño limpio e intuitivo para una navegación rápida y sin complicaciones.
Diseño Adaptable: Funciona perfectamente tanto en dispositivos móviles como en computadoras de escritorio.

 Tecnologías Utilizadas

Frontend: HTML5, CSS3, JavaScript (o el framework/librería que utilices).

Control de Versiones: Git y GitHub.

 Instalación y Uso

Sigue estos pasos para ejecutar el proyecto en tu máquina local:

1. Clonar el repositorio

git clone https://github.com/ziomarapiccini-eng/Calculadora-IMC.git
cd Calculadora-IMC


2. Ejecución

Si es un proyecto web estático (HTML/CSS/JS), simplemente abre el archivo index.html en tu navegador predeterminado.

Si utiliza un entorno de ejecución (Node.js, Python, etc.), ejecuta los comandos correspondientes:

# Ejemplo si utiliza dependencias
npm install
npm start
